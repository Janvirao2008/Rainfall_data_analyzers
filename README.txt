
PROJECT TITLE: RAINFALL DATA ANALYZER

DESCRIPTION:
Rainfall Data Analyzer is a Python-based console application
used to analyze monthly rainfall data stored in a CSV file.

TECHNOLOGIES USED:
1. Python
2. Pandas
3. NumPy
4. Matplotlib

FEATURES:
1. Load rainfall data from CSV.
2. Remove invalid and negative rainfall records.
3. Calculate total and average rainfall.
4. Find maximum and minimum rainfall.
5. Calculate standard deviation.
6. Identify wettest and driest months.
7. Identify heavy rainfall months.
8. Compare rainfall with average rainfall.
9. Generate bar and line charts.

HOW TO RUN:
1. Install Python.
2. Install Pandas, NumPy and Matplotlib.
3. Open the project folder in VS Code.
4. Run main.py.
